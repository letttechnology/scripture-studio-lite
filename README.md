# Scripture Studio LITE

> Deep Dive into Scripture — High-precision scripture drawing, annotation, audio & video recording tool.

## Key Features
- Universal Web Scripture Embedding
- Dual Mode Input (Interact 👆 vs Draw ✏️)
- Persistent Login & Pro Features
- Standalone OS Installer Builds

## Build Tasks
Run npm run build:windows or press Ctrl + Shift + B in VS Code.
